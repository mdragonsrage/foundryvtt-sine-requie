# SineRequie System

![Foundry v13](https://img.shields.io/badge/foundry-v13-yellow)

This system is system created for Foundry VTT V13.

It is based on the Sine Requie Role Playing game made by [Serpentarium](https://www.serpentarium.net/)

It has been created following the [full tutorial on the Foundry Wiki](https://foundryvtt.wiki/en/development/guides/SD-tutorial)!
